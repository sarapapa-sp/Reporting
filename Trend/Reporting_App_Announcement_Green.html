⚙ How to Execute
1. Open Report Figures Review and load figures. If they are not already loaded, the app reads the Compta file and stores the figures in the Flat file.

2. If the source file changes after loading, use OVERRIDE to reload the updated figures.

3. Report Consistency and Reports Trend use the Flat file directly, avoiding repeated reads of the Compta file.

▥ About the Trends
The Reports Trend screen helps identify changes, outliers and patterns across reports and indicators, using multiple reference windows.
