New Reporting App – Now Available!
Review Figures  •  Check Consistency  •  Analyze Trends
Hi Team,

We are pleased to announce the new Reporting App, bringing together three screens to load and review report figures, check consistency, and analyze trends in one place. The aim is to simplify the reporting workflow, reduce repeated file reads, and make analysis more accessible.
The App Consists of 3 Screens
1. Report Figures Review

Loads report figures from the Compta file into a central Flat file, and allows users to review the figures.
2. Report Consistency

Reads figures from the Flat file to review consistency and identify potential reporting discrepancies.
3. Reports Trend

Uses the Flat file to analyze movements, anomalies, and trends across different historical periods.
How to Execute
  1. Open Report Figures Review and load the report figures. If not already loaded, the application reads the Compta file and saves the figures to the Flat file.
  2. If the Compta file changes after loading, use OVERRIDE to reload the updated figures.
  3. Open Report Consistency or Reports Trend. Both screens read the stored Flat file directly, rather than repeatedly opening the Compta file.

About the Trends

The Reports Trend screen helps assess reporting movements across several reference periods. Historical windows exclude the selected COB from their reference observations.

Trend periodReference observations
ShortPrevious 5 business days
LongPrevious 60 business days
BroadPrevious 100 business days
Current MonthCurrent month; minimum 7 historical observations
Current QuarterCurrent quarter; minimum 10 historical observations
Current YearCurrent year; minimum 20 historical observations
Trend Visualizations & Analysis

Heatmap: Highlights changes and relative magnitudes across COB dates.
Line Charts: Show the evolution of report figures over time.
Threshold Analysis: Helps assess figures against historical reference distributions.
Z-Scores & Anomalies: Indicate how far a value lies from its historical mean, measured in standard deviations.
Excel Export: Enables further review of trend data and visualizations.
